# 🚀 Inicio Rápido - 5 Minutos

## Paso 1: Descargar los archivos
```
Descarga estos 2 archivos:
✅ index.html     (el sitio web)
✅ README.md      (guía completa)
```

## Paso 2: Abrir en Visual Code
```
1. Abre Visual Code
2. Ctrl+K Ctrl+O (Windows) o Cmd+K Cmd+O (Mac)
3. Selecciona la carpeta donde guardaste index.html
4. Haz doble clic en index.html en el explorador de archivos
```

## Paso 3: Instalar Live Server
```
1. Abre el panel de extensiones (Ctrl+Shift+X)
2. Busca "Live Server"
3. Instala la de Ritwick Dey
4. Haz clic derecho en index.html → "Open with Live Server"
```

## Paso 4: Ver en el navegador
```
🎉 ¡El sitio se abre automáticamente en http://localhost:5500
Cualquier cambio que hagas se ve en tiempo real!
```

## 🎨 Cambios más comunes (primeros 10 minutos)

### 1. Cambiar nombre de la academia
Busca en el editor: `DataVision` y reemplaza por tu nombre

Lugares donde aparece:
- Línea 88: Navbar
- Línea 310: Footer title
- Línea 315: Copyright

### 2. Cambiar color principal
Busca: `#6366f1` y reemplaza por tu color

Colores sugeridos:
```
Azul: #1e40af
Púrpura: #6d28d9
Verde: #059669
Naranja: #ea580c
```

### 3. Cambiar números de estadísticas
Busca la sección "STATS" (alrededor de línea 163-175)
```html
<h3>+5,000</h3>           ← Cambiar este número
<p>Estudiantes Activos</p> ← Cambiar este texto
```

### 4. Agregar tu WhatsApp real
Busca: `+51 999 999 999` y reemplaza con tu número

Formato: `+[código país] [número]`
- Perú: +51
- Colombia: +57
- México: +52
- Argentina: +54

### 5. Agregar tu email
Busca: `hola@datavision.com` y reemplaza

## 🆘 Troubleshooting rápido

**¿El sitio no se ve?**
- Recarga: Ctrl+Shift+R (limpiar caché)

**¿Live Server no funciona?**
- Instala la extensión de Ritwick Dey (no hay otra)

**¿Los colores no cambian?**
- Busca bien el código (#6366f1)
- Asegúrate de guardar (Ctrl+S)

**¿Cómo veo los leads capturados?**
- Presiona F12 en el navegador
- Ve a Console
- Escribe: `verLeads()`
